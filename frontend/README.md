# Fullstack Auth Demo App

A modern fullstack application featuring a **React + Vite** frontend and a **Node.js/Express** backend. This project demonstrates a secure authentication flow using Login/Signup, protected routes, and session management via cookies.

## 🚀 Live Demo


## 🏗️ Project Structure
The project is split into two main directories:

* **/frontend**: React application built with Vite and Tailwind CSS.
* **/backend**: Node.js & Express server handling API logic and sessions.

## ✨ Features
* **Secure Auth:** Signup and Login functionality.
* **Session Management:** Uses cookie-based sessions for persistent login states.
* **Protected Dashboard:** A static dashboard accessible *only* to authenticated users via `react-router-dom` guards.
* **Responsive UI:** Built with Tailwind CSS for a sleek, mobile-first design.
* **Client-Side Routing:** Smooth navigation using React Router.

## 🛠️ Tech Stack

### Frontend
* **React (Vite)**
* **Tailwind CSS** (Styling)
* **React Router DOM** (Navigation & Protected Routes)
* **Axios** (API Requests)

### Backend
* **Node.js & Express**
* **Cookie-Parser / Express-Session** (Session handling)
* **Bcrypt.js** (Password hashing)
